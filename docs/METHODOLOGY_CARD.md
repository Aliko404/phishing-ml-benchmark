## 2. Тип исследования

**Количественное (экспериментальное).** Все выводы строятся на числовых метриках (accuracy, precision, recall, F1, время инференса), измеряемых в контролируемом эксперименте на одном наборе данных с фиксированным разбиением, и проверяются статистическими тестами. Качественные методы (интервью, контент-анализ) не используются: цель — измеримое сравнение алгоритмов и эффекта отбора признаков, а не интерпретация мнений.

## 3. Формулировка гипотез

Гипотезы Task 1 уточнены: H1 («высокая точность») операционализирована порогом, H2 и H3 сделаны статистически проверяемыми.

**Гипотеза A (RQ1) — точность обнаружения**
- **H₀(A):** истинная accuracy лучшего классификатора на тестовой выборке не превышает 95 % (accuracy ≤ 0,95).
- **H₁(A):** истинная accuracy лучшего классификатора превышает 95 % (accuracy > 0,95).

**Гипотеза B (RQ2) — сравнение алгоритмов**
- **H₀(B):** медианные значения F1-score и времени инференса для всех сравниваемых алгоритмов равны (различий нет).
- **H₁(B):** существует хотя бы одна пара алгоритмов, различающихся по F1-score или по времени инференса (уровень значимости α = 0,05; тест Фридмана + post-hoc Вилкоксона с поправкой Холма по повторным фолдам).

**Гипотеза C (RQ3) — отбор признаков**
- **H₀(C):** отбор признаков не изменяет F1-score и время инференса относительно модели на полном наборе признаков (ΔF1 = 0, Δtime = 0).
- **H₁(C):** отбор признаков изменяет F1-score и/или снижает время инференса относительно полного набора признаков (ΔF1 ≠ 0 или Δtime < 0), α = 0,05.

## 5. Метрики и Baseline

- **Первичная метрика (Primary):** F1-score по классу «phishing» на тестовой выборке (для гипотезы A дополнительно — accuracy с 95 % доверительным интервалом). F1 выбран, так как баланс precision и recall важнее accuracy при возможном дисбалансе классов.
- **Вторичные метрики:** accuracy, precision, recall, время инференса (мс/объект), время обучения, пиковая RAM.
- **Пороговые метрики (Guardrail):**
  - recall по классу «phishing» ≥ 0,90 (пропуск фишинга недопустим);
  - время инференса ≤ 5 мс на объект;
  - пиковая RAM при обучении ≤ 1024 МБ;
  - отсутствие неудачных запусков (status ≠ ok).
  Модель, не прошедшая guardrail, не может считаться «лучшей», даже при высоком F1.
- **Baseline (контрольная точка):** Logistic Regression на полном наборе признаков без отбора — простой, интерпретируемый и стандартный линейный классификатор; результат любой другой конфигурации сравнивается с ним через `f1_delta_vs_baseline`. Для гипотезы C базой служит та же модель того же алгоритма с `feature_selection = none`.

## 6. Ограничения и план валидации

- Тестовый запуск использует синтетический сэмпл из 10 строк, только для проверки работы пайплайна.
- На Неделе 7 hold-out заменяется повторной стратифицированной k-fold валидацией для статистических тестов.
- Результаты зависят от выбранного датасета и могут не переноситься на новые фишинговые сайты (ограничение внешней валидности).
